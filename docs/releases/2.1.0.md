# doubao-linux 2.1.0

安装收敛成字面意义上的一条命令。

## 一条命令

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/dunova/doubao-linux/master/bootstrap.sh)
```

它会取回对应版本的仓库、校验 tag、然后自动装完打字、语音、外观，并起好服务。

## 相比 2.0.0

### 不再需要先 clone

新增 `bootstrap.sh` 自举入口。之前你得先 `git clone` 再 `./install.sh`，现在是：

```
一条命令 → 取仓库（钉 tag）→ install.sh → 装完
```

`bootstrap.sh` 只负责取回和校验，不重复实现任何安装逻辑。

### 自动处理 input 组

之前安装完会提示你自己跑 `sudo usermod -aG input`，现在安装器直接做掉（需要一次 sudo），
并记入台账。不想要这个行为就加 `--no-group-change`。

组变更只在下次登录生效，所以装完仍需要注销重登一次——但打字本身装完即可用，
只有语音注入和部分热键要等重登。

### 修了一个 `curl | bash` 的坑

`curl … | bash` 时 stdin 是管道，`sudo` 拿不到终端、读不了密码，表现是卡住不动。

现在的处理：

- 文档推荐 `bash <(curl …)`，终端留给脚本，`sudo` 正常交互
- `bootstrap.sh` 检测到 stdin 不是终端时，会主动把 stdin 重新绑到 `/dev/tty`
- 真没有终端时明确报错并给出正确用法，而不是静默卡住

### 输出更干净

自举过程原先会刷一屏 git 的 detached HEAD 提示和一个 annotated tag 警告。
现在统一走 fetch + 解引用 checkout，只留三行进度。

## 已知边界（未变）

- 仅 x86_64 / Arch 系。官方引擎是 x86 DLL，其他发行版见 `docs/INSTALL.md`
- 官方引擎会自行联网（云候选、账号、词库），这是官方设计
- 官方引擎与词库不随本仓库分发，安装时从官方 CDN 下载并校验
- 性能数据仍是引擎 `0.9.0.0` 时期实测的（1.90 ms/键、334 MB），`0.9.2.7` 下未重测
