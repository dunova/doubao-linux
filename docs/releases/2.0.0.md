# doubao-linux 2.0.0

打字、语音、外观，一条命令装齐。这是第一个把三部分打包在一起的版本。

## 装什么

| 部分 | 组件 | 版本 |
|---|---|---|
| 打字 | Fcitx5 桥接 + 官方豆包 Windows 引擎 | 引擎 `0.9.2.7`，桥接 `0.1.0-rc.2` |
| 语音 | Doubao Say | `v1.8.1` |
| 外观 | Doubao-Compact 主题 + 候选栏 + 语音动效 | 本仓库 |

## 怎么装

```bash
git clone https://github.com/dunova/doubao-linux.git
cd doubao-linux
./verify-deps.sh
./install.sh --dry-run
./install.sh
```

只在装系统包时用一次 `sudo`。

## 相比 1.0.0

**新增语音**。Doubao Say 是独立上游项目（MIT），本仓库不复制其源码，而是按其 Python 版本
（3.11/3.12/3.13/3.14）从上游 Release 下载对应离线包、校验 SHA-256 后调用它自己的安装器。
另外补了上游没有的 `doubao-say.service`，让语音跟键盘一样由 systemd 托管。

**新增外观**。三条改动：

- `Doubao-Compact` 主题：纯色不透明候选栏、iOS 蓝 `#0A84FF` 高亮、紧凑边距。
  刻意不用 SVG 背景（高 DPI 下模糊）、`ScaleWithDPI=False`（否则边距被放大失控）。
- 候选栏横向排列、屏幕级 DPI、**分数缩放修正**。最后这条修的是真 bug：
  1.6 倍缩放下候选窗口会偏离光标，根因是 classicui 走了 `wl_output.scale(2)`
  而不是 `wp_fractional_scale(1.6)`。
- 语音波形条样式与完整动效。

配置改动走 `scripts/merge_conf.py` 做**键级合并**，只改目标键，你的其它配置、
注释、自定义节原样保留。

**引擎升级** `0.9.0.0` → `0.9.2.7`。校验和同步更新；官方在不改 URL 的情况下换过文件内容，
所以校验失败一律中止，不做"尽力继续"。

**桥接升级**到 `0.1.0-rc.2`，包含我们提交的「候选排列跟随全局设置」修复（上游 PR #4）。

**安装脚本模块化**：`install.sh` 变成编排器，步骤拆到 `scripts/` 下四个阶段文件。
新增 `--no-voice`、`--no-appearance`、`--only-appearance`、`--check`。

**回退更精确**：所有写入记入 `~/.cache/doubao-linux/ledger/<时间戳>/`，
`rollback.sh` 按台账逆序还原，再调上游卸载器，最后移出残留。只移不删。

## 已知边界

- 不是 Windows 版的完整移植。外观页面、部分快捷键未迁移。
- 官方引擎会自行联网（云候选、账号、词库同步），这是官方设计。介意隐私请用纯本地输入法。
- Wayland 在 Hyprland 下实测可用，未对所有合成器逐一验证。
- 仅 x86_64。官方引擎是 x86 DLL，ARM 需模拟层。
- 性能数据来自 1.0.0（引擎 0.9.0.0）：单次按键 1.90 ms 中位、匿名内存 334 MB。
  0.9.2.7 下未重测，量级应相近。

## 升级方式

从 1.0.0 升级：

```bash
git pull
./install.sh
```

脚本幂等，已装的部分会跳过；引擎版本变了会重建 Wine 环境。
建议先 `./rollback.sh --snapshot`。
